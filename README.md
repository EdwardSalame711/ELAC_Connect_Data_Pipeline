# ELAC Connect — Four-Screen Prototype

[Link to APP PROTOTYPE Site](https://edwardsalame711.github.io/ELAC_Connect_Data_Pipeline/)

## Run it in VS Code

1. Open the `elac-connect-app` folder in VS Code.
2. Open `index.html` in a browser, or install the **Live Server** extension and choose **Open with Live Server**.
3. Use the sidebar, pipeline cards, and action buttons to move among the four screens.

## Included interactions

- Responsive desktop/mobile layout
- Four navigable screens
- Native `.csv` file picker for importing a dirty Penji export
- Selected-file validation and imported-record count
- Error-resolution buttons and confirmation feedback
- Missing-record filters
- Working cleaned-data CSV download

No build step or package installation is required.
